# Назначение разработки

Веб-сервер, который реализует функциональность планировщика задач.

API содержит следующие операции:
- добавить задачу
- получить список задач
- удалить задачу
- получить параметры задачи
- изменить параметры задачи
- отметить задачу как выполненную

По умолчанию веб-сервер доступен по ссылке http://localhost:7540/

# Содержимое директорий

**tests**: тесты для проверки API

**pkg/api**: CRUD-функции уровня API

**pkg/db**: CRUD-функции уровня Базы Данных

**pkg/server**: обеспечение работы сервера (по умолчанию используется порт 7540)

# Релизованные дополнительные задания

- Поддержка переменных окружения
- Реализация всех недельных и месячных правил повторения
- Поиск задач по дате или тексту
- Аутентификация по JWT-токену 
- Подготовка образа Docker
